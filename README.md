# VectorCraft 2D 

An interactive, web-based 2D vector mathematics visualizer and calculator designed to make vector arithmetic completely intuitive. Built with pure, html css js web technologies, this tool bridges the gap between raw algebraic formulas and clear, interactive visuals—perfect for students, math enthusiasts, and game developers working with physics engines like Pygame.

🔗 **Live Demo:** [vectormathbyarpan.netlify.app](https://vectormathbyarpan.netlify.app/)

---

# Features

Interactive 2D Canvas: Click, drag, and manipulate vectors dynamically on an interactive coordinate grid.
Real-Time Computations: Instant feedback on essential vector operations without reloading.
*Supported Operations:*
Vector Addition & Subtraction
Scalar Multiplication
Magnitude (Length) & Direction (Angle) calculation
Dot Product & Cross Product visualization
Lightweight & Fast: Zero external dependencies or heavy frameworks—just pure, high-performance web engineering.

---

# Built With

HTML5: Semantic structure and native canvas API rendering.
CSS3: Modern, responsive, and clean user interface layout.
JavaScript (JS): Core mathematical engine, vector logic, and event handling.
